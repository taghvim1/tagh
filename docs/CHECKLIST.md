# چک‌لیست سفر

- منو ← «چک‌لیست سفر» (بالای یادداشت‌ها) ← `/checklist` (کاشی‌های دو ستونه) ← `/checklist/<نوع>`.
- قالب‌های آماده: `src/checklist/templates.ts` (هر نوع: دسته‌های مخصوص + مدارک، بهداشت، الکترونیک). شناسهٔ آیتم‌ها (`دسته.شماره`) را عوض نکنید؛ آیتم تازه را به انتهای دسته اضافه کنید تا تیک کاربران نپرد.
- داده‌ی کاربر فقط روی همان دستگاه (localStorage، کلید `taghvim-checklists-v1`): تیک‌ها، آیتم/دستهٔ افزوده و نوع‌های سفر شخصی. آفلاین کامل کار می‌کند و به سرور/پنل نیازی ندارد.
- منطق خالص (قابل تست): `src/lib/checklists.ts`؛ تست: `tests/checklists.test.ts`.

# پکیج تور

صفحهٔ `/package` (منو ← «پکیج تور»، بالای «چک‌لیست سفر»): کاربر شهر مبدأ، مقصد، بودجه (اقتصادی/متوسط/لوکس + مبلغ اختیاری)، وسیلهٔ نقلیه، نوع سفر و تعداد روز (۱ تا ۳۰) را می‌دهد و سرور با هوش مصنوعی یک پکیج می‌سازد: برنامهٔ روزبه‌روز، مسیر، هزینهٔ تقریبی، «نکات مهم مقصد»، هشدارها و یک عکس تصادفیِ دارای مجوز از مقصد.

## جریان
1. `POST /api/package` (عمومی، ۴ درخواست در دقیقه برای هر IP چون هر کدام هزینهٔ AI دارد).
2. سرور جست‌وجوی وب (Tavily، اگر در «تنظیمات API» روشن باشد) ← پرامپت (از پنل) ← Gemini ← اعتبارسنجی JSON (یک بار تلاش مجدد با فهرست خطاها) ← انتخاب تصادفی یک عکس دارای مجوز (Wikimedia/Unsplash). نبود عکس خطا نیست.
3. دکمهٔ «علاقه‌مندی» پکیج را در `localStorage` (کلید `taghvim-saved-packages-v1`، حداکثر ۳۰) ذخیره می‌کند و «ابرک» (حباب ابری با پیوند «مشاهده») باز می‌شود. پکیج‌ها در صفحهٔ «علاقه‌مندی‌ها» بخش جدا دارند (باز کردن و حذف).

## پنل مدیریت ← «پکیج تور (پرامپت)»
- باکس پرامپت با پیش‌فرض حرفه‌ای (`server/src/package/prompt.ts`)؛ ذخیره، بازنشانی به پیش‌فرض، و روشن/خاموش‌کردن ویژگی برای کاربران.
- جاگذارها: `{{origin}} {{destination}} {{budget}} {{amount}} {{vehicle}} {{trip_type}} {{days}} {{schema}} {{sources}}`. چهارتای `origin، destination، days، schema` الزامی‌اند. یک قاعدهٔ ثابتِ «فقط JSON فارسی» همیشه به انتها اضافه می‌شود.
- «ساخت پکیج آزمایشی» با پرامپت ذخیره‌شده (حتی وقتی ویژگی برای کاربران خاموش است).
- مدل، کلیدها و جست‌وجوی وب/تصویر همان «تنظیمات API» است.

## نکته‌ها
- تنظیمات در KV کلید `package_settings`؛ بدون ذخیره‌ای، پیش‌فرض اعمال می‌شود.
- پاسخ‌ها شبکه‌ای‌اند؛ آفلاین فقط پکیج‌های ذخیره‌شده (متن) خوانده می‌شود و تصویرشان ممکن است نیاید.
